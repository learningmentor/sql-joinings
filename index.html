Visual Join Interactive Blueprint

A definitive conceptual guide and interactive mental model for when to use each join variety in industry work.

INNER JOIN Intersection

Returns only the records with matching keys in both Table A and Table B. Discards unmatched left and unmatched right records.

SELECT * FROM A
INNER JOIN B ON A.id = B.id;
LEFT JOIN Preserve Left

Returns all records from Table A, and matched records from Table B. If no match exists, Table B columns will be padded with NULL.

SELECT * FROM A
LEFT JOIN B ON A.id = B.id;
LEFT JOIN (IS NULL) Anti-Join

Finds "Orphans" or inactive entities: records in Table A that have no corresponding record in Table B (e.g. Customers who never ordered).

SELECT * FROM A
LEFT JOIN B ON A.id = B.id
WHERE B.id IS NULL;
FULL OUTER JOIN Union with Dups

Returns all records when there is a match in either left or right. In SQLite, achieved by combining LEFT JOIN and UNION.

SELECT * FROM A LEFT JOIN B
UNION
SELECT * FROM B LEFT JOIN A;
CROSS JOIN A × B

Calculates the Cartesian Product. Every row of Table A is paired with every row of Table B. 10 rows × 10 rows = 100 rows.

SELECT * FROM categories
CROSS JOIN stores;
SELF JOIN Unary Hierarchy

Joining a table to itself using aliases (e1, e2). Ideal for organizational hierarchies, manager-subordinate pairs, or sequential timestamp matches.

SELECT e.name, m.name AS manager
FROM staff e
JOIN staff m ON e.mgr_id = m.id;
